# Sunset Oia Fleet Showcase

First local React/Vite reconstruction of the approved fleet showcase.

## Run locally

1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, normally `http://localhost:5173`.

## Batch 1 includes

- Desktop header and bento layout.
- All 18 vessel cards.
- Large and standard card sizes.
- Working vessel-template links.
- Basic tablet/mobile responsiveness.
- Temporary preview images cropped from the supplied screenshots.
